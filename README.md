#  Chat-Box Backend

> **یک سرور قدرتمند و مقیاس‌پذیر برای اپلیکیشن چت لحظه‌ای**  
> ساخته شده با **Express.js، Socket.io، MongoDB و TypeScript**

---

## 📖 معرفی

این پروژه، **بک‌اند کامل** یک اپلیکیشن چت لحظه‌ای است که امکانات زیر را فراهم می‌کند:

- 🔐 **احراز هویت دو مرحله‌ای** (OTP + JWT در کوکی امن)
- 💬 **ارسال و دریافت پیام به‌صورت بلادرنگ** با Socket.io
- 👥 **مدیریت چت‌ها و کاربران** با MongoDB
- 🛡️ **امنیت بالا** (هش رمز، اعتبارسنجی با Zod، کوکی httpOnly)
- 📱 **قابلیت جستجوی کاربران** و ایجاد چت جدید

این پروژه به‌گونه‌ای طراحی شده که **تمیز، ماژولار و قابل توسعه** باشد.

---

## 🛠️ تکنولوژی‌ها

| دسته | تکنولوژی |
|------|-----------|
| **زبان** | TypeScript |
| **Runtime** | Node.js |
| **فریم‌ورک** | Express.js 5 |
| **دیتابیس** | MongoDB + Mongoose ODM |
| **بلادرنگ** | Socket.io |
| **احراز هویت** | JWT (jsonwebtoken) + bcryptjs |
| **اعتبارسنجی** | Zod |
| **مدیریت فایل** | Multer |
| **متغیرهای محیطی** | dotenv |
| **ابزار توسعه** | ts-node, nodemon  |
